# Изгиб Питона

Классическая игра «Змейка» на Python и pygame, написанная на принципах ООП.

## Правила

- Змейка движется по полю 640×480, разделённому на клетки 20×20.
- Управление: стрелки на клавиатуре. Развернуться на 180° нельзя.
- Съеденное яблоко увеличивает змейку на один сегмент.
- Через границы поля змейка проходит насквозь и появляется с противоположной стороны.
- Если змейка столкнулась сама с собой, игра начинается заново.

## Запуск

1. Установите Python 3.10 или новее.
2. Установите зависимости:

   ```
   pip install -r requirements.txt
   ```

3. Запустите игру:

   ```
   python snake.py
   ```

## Структура кода

- `GameObject` — базовый класс игровых объектов (позиция, цвет, метод `draw`).
- `Apple` — яблоко со случайной позицией.
- `Snake` — змейка: движение, отрисовка, смена направления, сброс.
- `handle_keys()` — обработка нажатий клавиш.
- `main()` — основной игровой цикл.
